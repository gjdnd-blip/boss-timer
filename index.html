📲 홈 화면에 추가

폰 홈 화면에 아이콘을 추가해서 눌러 바로 열 수 있어요. 앱스토어에서 받는 앱은 아니에요.

환경설정

알림 시간

쿨타임이 끝나기 얼마 전에 폰으로 알림을 보낼지 정해요. 여러 개 추가하면 여러 번 받아요. 0이면 끝나는 순간에 보내요. 알림이 필요 없는 보스는 보스 쿨타임 탭에서 🔔 버튼으로 끌 수 있어요. 알림은 3일 앞까지만 예약돼서, 더 먼 알림은 시각이 3일 안으로 들어온 뒤 사이트를 열어야 예약돼요.
이 설정은 지금 쓰는 기기에만 저장돼요.

보스 쿨타임

쿨타임은 게임에서 확인한 값을 직접 입력하세요. 보스에 입장한 직후 "입장" 버튼을 누르세요.

📱 휴대폰 알림 설정

  1. 휴대폰에 ntfy 앱 설치 (무료, 안드로이드/아이폰)
  2. 앱에서 + 눌러 아래 채널 이름을 구독
  3. 이 페이지에서 "입장"을 누르면 알림이 예약돼요. 알림 시각은 ⚙ 환경설정에서 정하고, 보스마다 🔔 버튼으로 켜고 끌 수 있어요
⚠ 알림 예약은 최대 3일 앞까지만 가능해요
· 알림 시각이 입장 후 3일 안이면 "입장"을 누를 때 바로 예약돼요.
· 3일보다 멀면(7일 보스 등) 그때는 예약되지 않고, 알림 시각이 3일 안으로 들어온 뒤에 이 사이트(또는 홈 화면 아이콘)를 한 번 열어야 자동 예약돼요.
· 예) 7일 보스, "1일 전" 알림 → 알림은 입장 6일 뒤라서, 입장 3일 뒤~6일 뒤 사이에 사이트를 한 번 열어야 해요. 그동안 한 번도 안 열면 알림이 오지 않아요.
· 보스 행에 📱예약 대기는 아직 예약 전, 📱예약됨은 예약 완료예요.
· 사이트를 안 열어도 확실히 받으려면 보스 행의 📅 버튼으로 구글 캘린더에 등록하세요.
⚠ 알림 예약 시 보스 이름과 시각이 ntfy.sh 서버로 전송돼요. 채널 이름을 아는 사람은 알림을 볼 수 있으니 공유하지 마세요.

📅 기록

보스에 "입장"을 누르면 보스 기록이 자동으로 쌓여요. 사냥은 날짜를 누른 뒤 "사냥" 탭에서 직접 추가해요. 기록마다 수익·지출을 넣을 수 있고, 달력 동그라미 옆 숫자는 순수익이에요.

💊 포션 가격 세트
자주 쓰는 포션 가격을 이름 붙여 저장해 두세요. 기록의 "사냥 전/후로 자동 계산"에서 세트를 고르면 가격이 한 번에 채워져요. 가격은 직접 입력하세요.
🎨 색깔 지정
달력에 표시되는 색과 모양이에요. 색 칸을 눌러 색을, 옆의 선택칸에서 모양을 바꿀 수 있어요.

⚙ 장비 효율 계산기

캐릭터마다 입력값이 따로 저장돼요. 위쪽 캐릭터 선택과 같이 움직여요.
"스탯 : 공격력" 비율로 모든 능력치를 환산 스탯(스탯 + 공격력 × 비율)으로 통일해서, 부위별 다음 업그레이드의 스탯 1당 비용이 낮은(가성비 좋은) 순서로 보여줘요. 값을 입력하면 바로 계산돼요. 가격은 1억, 2500만, 4억3천만처럼 단위를 붙여 써도 돼요.

부위별 입력

작은 화면에서는 표를 좌우로 밀어서 볼 수 있어요. "적용"을 누르면 다음 아이템 값이 현재 장비 칸으로 옮겨져요.

⏱ 분당 경험치 계산기

한 타임 동안 얻은 경험치 총량을 넣으면 분당 경험치를 계산해요. 한 타임은 기본 60분이고, 더 오래(또는 짧게) 했다면 시간(분)을 직접 입력해서 바꿀 수 있어요. 경험치 쿠폰(2배/3배, 각 15분)을 썼다면 장수를 지정하세요. 쿠폰을 쓴 시간은 2배/3배로 얻은 것으로 보고, 쿠폰 효과를 뺀 기본 분당 경험치를 구해요. 1.2억, 3500만, 4억3천만, 사천만처럼 단위나 한글 숫자로 써도 돼요.
